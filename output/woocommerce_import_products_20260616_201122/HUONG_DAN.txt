HUONG DAN IMPORT LEN WOOCOMMERCE (veexovar.com / shop khac)
=====================================================

TAI SAO ANH BI LOI?
1. URL anh Redbubble co dau phay (,) -> WooCommerce cat sai link khi import
2. WordPress bi Redbubble chan (403) khi tai anh ve server

CACH FIX (LAM 1 LAN):

BUOC 1 - Them code vao WordPress
  Copy noi dung file wordpress-image-fix.php vao cuoi file:
  Appearance -> Theme File Editor -> functions.php (theme child)

  Hoac upload file wordpress-image-fix.php len server va require trong functions.php:
  require_once get_stylesheet_directory() . '/wordpress-image-fix.php';

BUOC 2 - Import CSV
  WooCommerce -> Products -> Import
  Chon file products.csv
  Map cot "Images" -> Images
  Run import

BUOC 3 - Kiem tra
  Mo san pham -> anh featured phai hien thi
  Neu van loi: xem thu muc images/ (anh tai san) va upload thu cong qua Media

COT Images TRONG CSV:
- Dung URL anh day du, nhieu anh ngan cach bang dau | (pipe)
- KHONG dung dau phay de ngan cach anh (gay loi voi URL Redbubble)
- Anh uu tien: artwork (thiet ke goc) + product mockup

THU CONG (neu auto import anh van loi):
1. Upload file trong thu muc images/ vao Media Library
2. Sua CSV cot Images -> chi de ten file: vi-du-anh.jpg
3. Import lai (anh phai nam trong wp-content/uploads/thang-hien-tai/)


Thong ke:
- Tong san pham: 10
- Tai anh local thanh cong: 10
- Dung URL trong CSV: 0
